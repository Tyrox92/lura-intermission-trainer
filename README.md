# L'ura Crystal Trainer

Kleines Vite/React-Minispiel zum Trainieren der L'ura Intermission Crystal-Drop-Mechanik.

## Lokal starten

```bash
npm install
npm run dev
```

## Build testen

```bash
npm run build
npm run preview
```

## Vercel

Build Command: `npm run build`  
Output Directory: `dist`  
Framework Preset: Vite
